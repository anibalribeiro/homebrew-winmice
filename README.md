# homebrew-winmice

Homebrew tap for [WinMice](https://github.com/anibalribeiro/WinMice).

```bash
brew tap anibalribeiro/winmice
brew trust anibalribeiro/winmice
brew install --cask winmice
```

Release builds are **Developer ID signed and notarized** by Apple. Grant
Accessibility when prompted. If upgrading from an older ad-hoc build, remove
old WinMice Accessibility entries and re-enable `/Applications/WinMice.app`
once.
